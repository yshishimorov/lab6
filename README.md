## Веб-программирование на Python (Flask, Jinja2, SQLite, Bootstrap 5)

Веб-приложение разработано в рамках курса «Методы и технологии программирования» (часть 1, лабораторная работа №6) по **Варианту 1**. Приложение реализовано с соблюдением требований на **повышенную оценку** (выполнены 3 задания средней сложности и 2 задания повышенной сложности).

---

### Выполненные задания (Вариант 1)

| Уровень сложности | № задания | Формулировка задания | Реализация в проекте |
| :--- | :---: | :--- | :--- |
| **Средняя сложность** | **1** | Flask-приложение «Hello World» | Маршрут `/hello` с поддержкой динамического query-параметра `?name=...` и приветственной страницей |
| **Средняя сложность** | **3** | Статическая страница + CSS | Внешний CSS-файл `static/css/style.css`, градиенты, тени, оформление карточек и страница `/static-demo` |
| **Средняя сложность** | **5** | Страница с Bootstrap | Интеграция Bootstrap 5.3 во всех шаблонах: адаптивная навигация, сетка (Grid), карточки, формы, бейджи и Flash-уведомления |
| **Повышенная сложность** | **1** | Flask с базой SQLite (CRUD) | Полноценный CRUD для заметок (`/notes`): создание, просмотр, редактирование, удаление, поиск по тексту и фильтрация по категориям |

### Архитектура и структура проекта

Приложение построено с использованием шаблона **Application Factory** (`create_app`) и модульных компонентов **Blueprint** (`main_bp`), что обеспечивает расширяемость и простоту тестирования:

```text
Лабораторная работа №6/
├── src/
│   ├── __init__.py           # Пакет исходного кода приложения
│   ├── config.py             # Конфигурация приложения (пути, секретный ключ, ограничения файлов)
│   ├── database.py           # Модуль работы с SQLite (подключение, инициализация таблиц, CRUD-функции)
│   └── routes.py             # Контроллеры и маршруты Blueprint (Flask view functions)
├── static/
│   ├── css/
│   │   └── style.css         # Авторские стили CSS, оформление интерфейса
│   └── js/
│       └── main.js           # Клиентские скрипты (автозакрытие flash-сообщений, подтверждения удаления)
├── templates/
│   ├── base.html             # Базовый макет Jinja2 с навигационной панелью Bootstrap 5 и flash-контейнером
│   ├── index.html            # Главная информационная панель со статистикой и карточками заданий
│   ├── hello.html            # Демонстрация задания №1 («Hello World»)
│   ├── static_demo.html      # Демонстрация задания №3 (CSS-стили и оформление)
│   ├── items/
│   │   ├── list.html         # Просмотр списка заметок с поиском и фильтром по категории (Read)
│   │   ├── detail.html       # Детальный просмотр отдельной заметки (Read One)
│   │   ├── create.html       # Форма добавления новой заметки (Create)
│   │   └── edit.html         # Форма редактирования заметки (Update)
│   └── uploads/
│       └── upload.html       # Веб-форма отправки файлов и таблица загруженных файлов
├── uploads/
│   └── .gitkeep              # Директория для хранения загружаемых пользователями файлов
├── instance/                 # Локальное хранилище базы данных SQLite (app.db)
├── tests/
│   ├── __init__.py
│   ├── test_app.py           # Тесты базовой маршрутизации, конфигурации и статики
│   ├── test_crud.py          # Тесты операций CRUD и валидации базы данных SQLite
│   └── test_upload.py        # Тесты загрузки файлов, валидации расширений и скачивания
├── app.py                    # Фабрика приложений Flask и точка экспорта `app`
├── main.py                   # Консольная точка входа с поддержкой аргументов командной строки
├── requirements.txt          # Зависимости проекта (Flask, pytest)
└── README.md                 # Документация проекта
```

### Установка зависимостей

Для работы приложения требуется Python версии 3.10 или выше.

```bash
pip install -r requirements.txt
```

---

### Запуск веб-приложения

Запуск через главный модуль:

```bash
python main.py
```

После запуска приложение доступно в браузере по адресу:
[http://127.0.0.1:5000](http://127.0.0.1:5000)

Дополнительные параметры запуска:
* `python main.py --help` — справка по аргументам;
* `python main.py --port 8080` — запуск на указанном порту;
* `python main.py --check` — проверка корректности регистрации маршрутов и путей к БД без старта сервера.

### Запуск модульных тестов

В проекте реализован полный набор юнит-тестов, охватывающий все маршруты, валидацию форм, работу с SQLite и загрузку файлов:

```bash
python -m unittest discover tests -v
```

Все тесты выполняются в изолированном тестовом окружении с временными каталогами и тестовой базой данных.
